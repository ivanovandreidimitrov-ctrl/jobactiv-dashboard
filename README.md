# JobActiv 📄🎯

## Ce este
Agent activ pentru căutare și gestionare carieră — transformă skill-urile dobândite prin SmartLola în poziții profesionale reale.

## Obiectiv
Saltul de la activitate preponderent fizică (șantier) → activitate preponderent intelectuală (tech, AI, automatizări).

## 🧭 IDENTITATEA ANDREI — Punctul forte central

**Andrei nu e "muncitor care a învățat programare". Este expert în edilizia care a construit un sistem AI real.**

### Intersecția care îl face unic
- **10+ ani pe șantier** — coordonator 5 șantiere simultan, 20 operatori, 4-5 echipe. Știe problema reală din teren.
- **20 luni construind SmartLola** — 15 agenți AI, DB SQLite, dashboard live GitHub Pages, app PWA vocală, integrări Telegram/WhatsApp, OCR, transcriere audio, backup automat, versionare Git. Știe soluția AI.
- **Această combinație e rară** — companiile de construction tech au nevoie de oameni care înțeleg ambele lumi. Absolvenții IT nu știu cum funcționează un șantier. Oamenii de șantier nu știu AI. Andrei știe ambele.

### Lucrarea în lumină (ce îl diferențiază)
1. **SmartLola = portfolio viu** — nu tutorial, nu curs. Sistem care funcționează zilnic cu date reale și utilizatori reali
2. **Progresul dovedește capacitatea de învățare** — din "ce e IT-ul" (Ian 2025) la "orchestrează 15 agenți AI" (Sep 2026). 20 luni, autodidact, în paralel cu munca fizică
3. **Vulnerabilitate ca forță** — nu pretinde că e altcineva. "Autodidact care a construit soluția" e brand-ul, nu scuză
4. **Edilizia + AI = piața lui** — Italia investește PNRR în digitalizarea ediliziei. Construction tech / PropTech caută exact oameni cu experiență mixtă
