# JobActiv 📄🎯

## Ce este
Agent activ pentru căutare și gestionare carieră — transformă skill-urile dobândite prin SmartLola în poziții profesionale reale.

## Obiectiv
Saltul de la activitate preponderent fizică (șantier) → activitate preponderent intelectuală (tech, AI, automatizări).
